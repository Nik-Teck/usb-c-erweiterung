# Arbeitsanleitung: USB-C-Erweiterung für das Netzteil

Schritt-für-Schritt-Bauanleitung (Version 0.5, Entwurf) für die USB-C-Erweiterung mit TPS25810-Logikboard und Adafruit-USB-C-Breakout.

**Anleitung online lesen:** über GitHub Pages dieses Repositories (Link steht unter *Settings → Pages*).

Die Seite ist als druckbare A4-Blätter aufgebaut. Zum Drucken im Browser „Drucken" wählen, Format A4, Skalierung 100 %.

Die 3D-Modelle (Halter, Testvorrichtung) gibt es auf Printables.
